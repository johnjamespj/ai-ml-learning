# AI/ML Learning Lab

A hands-on path from Python scientific computing to modern AI systems.

## How to use this repo
For every lesson:
1. Learn the intuition.
2. Work through the math.
3. Implement the core idea from scratch.
4. Use the production Python library.
5. Run an experiment.
6. Complete the exercises.
7. Build something.

Do not rush to frameworks. The goal is to understand what the library is doing for you.

## Learning rule
If you cannot explain what the inputs, outputs, parameters, objective/loss, and evaluation metric mean, the model is still a black box. Open the box.
