# Paper Activity 05: word2vec

**Paper:** Mikolov et al., "Efficient Estimation of Word Representations in Vector Space" (2013), arXiv:1301.3781.

## Reproduce
Implement a tiny skip-gram model on a small corpus.

Inspect nearest neighbors in embedding space.

## Experiments
Vary:
- context window
- embedding dimension
- minimum token frequency

## Explain
Why does predicting local context create semantic/syntactic structure in vectors?

## Caution
Do not overinterpret tiny-corpus analogy results. Data scale strongly affects embedding quality.
