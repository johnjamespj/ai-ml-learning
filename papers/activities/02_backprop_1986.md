# Paper Activity 02: Backpropagation

**Paper:** Rumelhart, Hinton & Williams, "Learning representations by back-propagating errors" (Nature, 1986), DOI: 10.1038/323533a0.

## Reproduce
1. Build a hidden-layer network using only NumPy.
2. Derive gradients by hand.
3. Gradient-check at least five parameters numerically.
4. Learn XOR.
5. Plot hidden-unit activations.

## Central evidence
A hidden layer plus backpropagation can learn internal representations that a single linear unit cannot.

## Ablation
Replace the nonlinear hidden activation with a linear one. Explain the result mathematically.

## Defense
Why is backpropagation an application of the chain rule rather than a special neural-network law?
