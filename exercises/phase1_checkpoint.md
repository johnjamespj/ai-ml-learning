# Phase 1 Checkpoint

Do this without looking at the lessons first.

## Concepts
1. Distinguish sample, feature, target, parameter and hyperparameter.
2. What is data leakage?
3. Why have train, validation and test data?
4. What does a dot product calculate?
5. Why is vectorization useful?
6. What does a gradient represent?
7. Why can a learning rate be too large?
8. Distinguish mean, variance and standard deviation.
9. Explain conditional probability.
10. What does model generalization mean?

## Coding challenge
Generate noisy data from:

y = 3x - 4 + noise

Then:
- visualize it;
- split train/test;
- implement linear regression with gradient descent using NumPy;
- train scikit-learn LinearRegression;
- compare coefficients and test MSE;
- plot predictions;
- write three conclusions.

## Gate
Move forward when you can explain your implementation line-by-line rather than merely make it run.
