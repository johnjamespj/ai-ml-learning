# Project 02: Classical ML Benchmark

## Mission
Build a defensible supervised-learning experiment rather than a leaderboard script.

Choose a tabular dataset and compare:
- dummy baseline
- logistic regression
- k-NN
- decision tree
- random forest
- gradient boosting
- SVM

## Required pipeline
1. Define the prediction problem.
2. Identify sample, features and target.
3. Perform EDA.
4. Identify leakage risks.
5. Establish a baseline.
6. Choose an appropriate split.
7. Put preprocessing in pipelines.
8. Cross-validate.
9. Report multiple relevant metrics.
10. Tune a small number of justified hyperparameters.
11. Evaluate once on a held-out test set.
12. Analyze errors.
13. Explain model complexity and limitations.

## Deliverables
- notebook or Python program
- README/report
- metric table
- confusion matrix for classifiers
- plots relevant to the task
- short error analysis
- reproducible seed/configuration

## Extra radar-flavored option
Generate synthetic signal observations with frequency, bandwidth, SNR, noise floor and interference features. Define a detection or signal-type classification problem and compare the same model families.
