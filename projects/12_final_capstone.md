# Project 12: Final AI/ML Capstone

Choose one problem substantial enough to require the whole workflow.

## Required phases
1. problem definition
2. data source/generation
3. EDA
4. baseline
5. split/evaluation design
6. classical model
7. neural model where justified
8. error analysis
9. robustness/domain-shift testing
10. reproducibility
11. deployment
12. monitoring plan

## Suggested capstones
- radar/RF interference classifier
- spectral anomaly detector
- technical-document RAG assistant
- time-series predictive-maintenance system
- vision system
- reinforcement-learning navigation experiment
- multimodal sensor fusion system

## Final defense
Explain:
- why this metric
- why this split
- why this model
- what simpler baseline it beats
- where it fails
- how deployment data may differ
- what evidence would make you distrust the result

The goal is engineering judgment, not merely a high score.
