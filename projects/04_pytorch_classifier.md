# Project 04: Production-style PyTorch classifier

## Mission
Turn your from-scratch knowledge into a clean PyTorch training system.

## Required structure
Create modules for:
- dataset
- model
- train loop
- evaluation
- configuration
- checkpointing

## Requirements
- Dataset/DataLoader
- train/validation/test split
- deterministic seed
- device-aware execution
- optimizer selection
- validation every epoch
- best-checkpoint saving
- early stopping
- confusion matrix
- learning curves
- test evaluation exactly once after model selection

## Debugging gate
Before full training, prove the model can overfit 32 samples.

## Report
Explain:
- model architecture
- parameter count
- optimizer
- loss
- batch size
- learning rate
- split strategy
- main failure modes
