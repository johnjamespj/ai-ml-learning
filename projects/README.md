# Projects

Projects turn the individual concepts into systems.

## P1: Regression laboratory
Implement linear regression from scratch, compare against scikit-learn, visualize residuals and explain failure cases.

## P2: Classification laboratory
Compare logistic regression, k-NN, trees, random forests and boosting on the same dataset. Justify the evaluation metric.

## P3: NumPy neural network
Implement forward propagation and backpropagation without PyTorch.

## P4: PyTorch classifier
Create a full Dataset/DataLoader/training/evaluation/checkpoint pipeline.

## P5: Spectrogram classifier
Generate or load time-series signals, compute spectrograms, train a classifier and investigate robustness to noise.

## P6: Mini Transformer
Implement scaled dot-product and multi-head attention, then assemble a small Transformer.

## P7: RAG system
Build ingestion, chunking, embeddings, retrieval and answer generation. Measure retrieval rather than judging only by demos.

## P8: RL agent
Train and evaluate an agent in a Gymnasium environment.

## P9: Production inference service
Serve a trained model through FastAPI, test it, containerize it and measure latency.

## Final capstone: Signal/Radar AI system
Construct an end-to-end pipeline from signal generation/ingestion through DSP preprocessing, features or learned representations, model training, validation, robustness testing and deployment.
