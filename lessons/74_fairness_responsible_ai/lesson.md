# Lesson 74: Responsible ML and fairness concepts

ML systems can produce unequal or harmful outcomes even when an aggregate metric looks good.

## Concepts
- representation bias
- measurement bias
- historical bias
- subgroup performance
- fairness metrics
- accessibility
- human oversight
- documentation

Different fairness definitions can conflict, so context and intended use matter.

## Exercise
Create a synthetic dataset with two groups whose data quality differs. Compare aggregate metrics against group-specific precision, recall and calibration.

## Documentation
Practice writing:
- intended use
- out-of-scope use
- data limitations
- known failure modes
- evaluation slices
- monitoring plan
