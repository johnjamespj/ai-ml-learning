# Mathematical Framework

Math is a required track in this course, not an optional appendix.

Start with [math/README.md](math/README.md).

The 17 mathematical notebooks cover:

1. notation and tensor shapes
2. linear algebra and geometry
3. calculus and matrix calculus
4. probability and Bayes
5. statistics and likelihood
6. information theory
7. optimization
8. linear models and decision boundaries
9. regularization and generalization
10. PCA, SVD, spectral methods, and kernels
11. neural-network mathematics
12. attention/Transformer mathematics
13. generative-model mathematics
14. reinforcement-learning mathematics
15. statistical signal/radar detection
16. Bayesian uncertainty and calibration
17. synthesis/derivation workshop

Use [math/MATH_MAP.md](math/MATH_MAP.md) to see which math notebook pairs with each AI/ML lesson and landmark paper.

Use [math/FORMULA_REFERENCE.md](math/FORMULA_REFERENCE.md) only as a reference after you have derived the result yourself.
